核心结论 TL;DR

传感器信号异常分三类：输出为0/ERR（断线或短路）、信号大幅波动（干扰或机械松动）、零点持续漂移（进水或温漂）。90%的问题可通过万用表测量激励电压（应为5V/10V）和绝缘电阻（应>500MΩ）两步初步定位。

  • 仪表显示ERR：先测激励电压（红黑线），正常5V/10V，异常查仪表供电
  • 仪表显示0且不变：测信号线（绿白线）mV输出，0mV且受力无变化→传感器损坏
  • 信号大幅波动：检查机械安装松动，确认电缆屏蔽层接地，仪表增大滤波时间常数
  • 零点缓慢漂移：测绝缘电阻，若<100MΩ为进水，若测量时温度变化>5℃为温漂
  • 热线：188 1190 6890，远程指导排查，通常10分钟内定位问题

一、信号异常类型分类与初步判断

称重传感器信号异常可以按表现形式分为三大类，每类有不同的排查思路：

异常现象可能原因优先检查
仪表显示ERR或报警超载、信号短路、仪表参数错误超载→激励电压→接线
显示固定值（不随物料变化）信号断路、传感器损坏、接触不良接线→激励→mV输出
信号大幅波动不稳定机械振动、电磁干扰、机械松动安装→接线→仪表滤波
零点缓慢漂移（偏高/偏低）进水、温度变化、蠕变绝缘电阻→温度→蠕变
精度下降（重复性差）机械磨损、弹性体疲劳、标定失效机械检查→重新标定

二、诊断工具准备

基本诊断需要以下工具：

  • 数字万用表（分辨率至少4位半，0.1mV级）——测激励电压和mV信号
  • 500V兆欧表（绝缘电阻表）——测传感器绝缘电阻（普通万用表量程不够）
  • 5V/10V稳压电源（可用仪表激励端，或备用直流电源）
  • 已知重量（砝码或已称量的物料）——验证精度

三、分步排查流程

故障一：仪表显示ERR或超量程

步骤1 → 检查物料是否超载（清空皮带）→ 若清空后正常：超载保护触发，正常
步骤2 → 检查量程设置（仪表菜单中的传感器满量程/灵敏度参数）→ 参数正确才进行下一步
步骤3 → 测激励电压（EX+/EX-）→ 应等于仪表设定值（5V或10V）
步骤4 → 测信号线（S+/S-）→ 空载应<±1mV，若远超（>5mV）则传感器受力或损坏
步骤5 → 断开仪表，用示波器或万用表AC档测信号线是否有干扰噪声

故障二：显示固定值，不随物料变化

步骤1 → 确认接线盒内所有接线端子没有松动（逐一拧紧）
步骤2 → 测传感器输入阻抗（EX+/EX-之间）→ 应为规格书标称值±10%（通常350Ω）
步骤3 → 测传感器输出阻抗（S+/S-之间）→ 应为规格书标称值±10%（通常350Ω）
步骤4 → 施加5V激励，测S+/S-空载mV输出 → 加载已知重量，若mV无变化：传感器弹性体或应变片损坏
步骤5 → 更换同规格传感器验证

故障三：信号大幅波动

步骤1 → 停机状态（皮带不运行，无振动）测信号稳定性 → 若停机稳定：振动/皮带问题
步骤2 → 检查传感器安装螺栓力矩（用扭矩扳手按规格书力矩重新紧固）
步骤3 → 检查电缆走线：信号电缆是否与动力电缆共管？ → 是：分离走线
步骤4 → 检查屏蔽层接地：屏蔽层是否仅在仪表端单点接地？ → 双端接地会引起地环流
步骤5 → 增大仪表滤波时间常数（建议从1s增大到3s，或启用自适应滤波）

故障四：零点漂移

步骤1 → 记录漂移规律（是随温度变化？随时间单向漂移？还是每天规律性变化？）
步骤2 → 测绝缘电阻（500V兆欧表）→ <100MΩ：进水导致的漂移，需干燥或更换
步骤3 → 若绝缘正常：观察漂移与温度的关系 → 若相关性强：温度漂移，改善安装防护
步骤4 → 若绝缘正常且与温度无关：蠕变累积 → 做完整物料标定重置基准
步骤5 → 若漂移>0.3%/天且无法控制：传感器老化需更换
