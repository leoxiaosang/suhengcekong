2. 短寿命件（0.5-2 年）：刮板 / 限位 / 密封

2.1 清扫器刮板（0.5-1 年）

作用：清理皮带背面粘料，防止物料进入秤架、托辊。

磨损判断：

  • 刮板磨损厚度 >50%（如 10mm 厚刮板磨到 5mm 以下）
  • 刮板边缘缺口 >5mm（刮不净物料）
  • 刮板与皮带不贴合（间隙 >2mm）

选型匹配：

  • 材质：聚氨酯（PU）通用，硬质合金用于高磨琢性物料（如焦炭、矿石）
  • 宽度：= 带宽 - 50mm（左右各留 25mm 间隙）
  • 数量：1 级清扫器 1 道，2 级清扫器 2 道（前后布置）

更换 SOP：停机 → 拧松压板螺栓 → 取出旧刮板 → 装新刮板（贴合皮带）→ 调整间隙 ≤1mm → 紧固螺栓 → 试运行

2.2 限位橡胶（1-2 年）

作用：防止秤架水平 / 垂直方向过载，保护传感器。

磨损判断：

  • 橡胶老化开裂（表面龟裂）
  • 橡胶变形 >30%（失去弹性）
  • 橡胶与金属脱粘

选型匹配：

  • 硬度：邵氏 A 60-70（不能太软，否则失去限位作用）
  • 尺寸：按原装尺寸（一般是 50×50×20mm 或类似）

更换 SOP：停机 → 拆下限位座 → 取出旧橡胶 → 装新橡胶（涂胶水 / 螺栓固定）→ 重新调整间隙 → 试运行

2.3 密封件 / 油封（1-2 年）

作用：防止粉尘、雨水进入称重传感器、托辊轴承、速度传感器。

磨损判断：

  • 密封件漏油 / 漏脂（托辊端盖）
  • 密封件老化变形（失去弹性）
  • 密封件破损 / 撕裂

选型匹配：按原装型号（不同厂家规格不同），必须用耐油橡胶（丁腈橡胶）。

更换 SOP：拆卸相关部件 → 取出旧密封 → 清洁密封槽 → 装新密封（涂润滑脂）→ 回装

3. 中寿命件（2-5 年）：托辊 / 皮带 / 电缆

3.1 托辊 / 托辊轴承（2-3 年）

作用：支撑皮带、减小摩擦。托辊不转是 20% 精度问题的根源。

磨损判断：

  • 托辊卡死不转（用手拨动测试）
  • 托辊有异响（轴承损坏）
  • 托辊径向跳动 >1mm（磨损严重）
  • 托辊表面磨损（局部凹陷 >1mm）

选型匹配（关键！）：

  • 直径：Φ89 / Φ108 / Φ133 / Φ159（按原规格）
  • 长度：= 带宽 + 200mm（机架宽度）
  • 轴承型号：6204 / 6205 / 6206（按原规格）
  • 称重段托辊：必须同厂家、同型号、同批次（避免皮重波动）

更换 SOP：停机 → 拆卡簧 / 螺栓 → 取出旧托辊 → 装新托辊（注意方向）→ 调整水平度 → 试运行

3.2 皮带（3-5 年）

作用：输送物料、提供称重平台。

磨损判断：

  • 上胶厚度：≥3mm（一般新皮带 6-8mm）
  • 下胶厚度：≥2mm
  • 皮带边缘：无开裂、无明显磨损
  • 皮带接头：无开裂、无错位
  • 覆盖胶龟裂：深度 >1mm

选型匹配：

  • 型号：EP / NN / ST（按原规格）
  • 强度：EP200 / EP300 / EP400（按载荷）
  • 宽度：按带宽（500 / 650 / 800 / 1000 / 1200 / 1400mm）
  • 覆盖胶厚度：4.5+1.5 / 6+3 / 8+3（按物料磨琢性）
  • 耐温：普通 60-80℃，耐热 100-150℃（热电厂用耐热）
  • 阻燃：煤矿 / 化工 / 井下必须阻燃（MT 标准）

更换 SOP（重！）：停机 4-8 小时 → 松张紧装置 → 拆旧皮带（分段切割）→ 装新皮带（用硫化接头或机械接头）→ 调整张力 → 试运行

硫化接头 vs 机械接头：

  • 硫化接头：寿命长、强度高（推荐），需专业硫化设备
  • 机械接头：安装快、成本低，但寿命短 30-50%，对精度秤不推荐（影响称重段平整度）

3.3 信号电缆（5-8 年）

作用：连接传感器、仪表、PLC，屏蔽和接地是抗干扰生命线。

磨损判断：

  • 电缆外皮龟裂 / 破损
  • 屏蔽层断裂 / 接地不良
  • 通断测试电阻异常

选型匹配：

  • 型号：RVVP 4×0.75mm²（屏蔽）
  • 长度：实测 + 1m 余量
  • 敷设：单独穿金属管，严禁与动力电缆同管

更换 SOP：记录原接线 → 拆旧电缆 → 穿新电缆 → 按图接线 → 测接地电阻 ≤4Ω → 校准

4. 长寿命件（5-8 年）：传感器 / 仪表

4.1 称重传感器（5-8 年）

作用：皮带秤的核心感知元件，决定精度上限。

更换判断（不是按时间！按状态）：

  • 精度劣化：动态精度连续 3 个月 >±0.5%
  • 零点漂移：无法校准到 ±0.1%/h 以内
  • 过载损坏：物料卡死 / 皮带断裂导致
  • 密封失效：内部进潮 / 进水
  • 电缆断裂：外力损伤

选型匹配（关键！选错 = 重新调试）：

  • 容量：= 秤的额定载荷 × 1.2-1.5 倍（安全系数）
  • 精度等级：C3 / C4（推荐 C4 配 0.5 级秤）
  • 输出灵敏度：2.0 ± 0.1 mV/V（行业标准）
  • 防护等级：IP67（一般）/ IP68（潮湿环境）
  • 数量：1/2/4 个，按原装数量
  • 厂家：尽量同厂家（原装优先）

更换 SOP：停机 → 拆电缆 → 卸传感器（注意限位）→ 装新传感器（预压缩量 0.2-0.5mm）→ 接线 → 调试（零点 + 量程）→ 实物标定

4.2 速度传感器（3-5 年）

作用：检测皮带速度，打滑 = 累计误差大。

更换判断：

  • 输出脉冲丢失（丢脉冲 = 累计误差）
  • 编码器损坏（光电式）
  • 滚轮磨损（接触式）
  • 密封失效（进灰）

选型匹配：

  • 类型：光电式（精度高） / 滚轮式（皮实）
  • 脉冲数：按原装（一般 100-2000 脉冲/转）
  • 信号：NPN / PNP（按仪表要求）

更换 SOP：停机 → 拆旧速度传感器 → 装新 → 调整间隙（光电式 2-5mm）→ 接线 → 试运行

4.3 仪表（5-10 年）

作用：信号处理、显示、通讯、累计。

更换判断：

  • 显示黑屏 / 花屏
  • 按键失灵
  • 通讯中断（RS485 / 以太网）
  • 精度异常且查不到其他原因
  • 固件升级失败

选型匹配：

  • 同厂家同型号（最简单，参数无需重新设置）
  • 同系列升级（如老款停产，升级到新款，注意接线定义）
  • 更换品牌（必须重新标定、改接线、改通讯协议）

更换 SOP：记录原参数 → 断电 → 拆线 → 换新仪表 → 接线 → 设置参数 → 调零点 → 调量程 → 通讯测试

5. 选型匹配：原厂 vs 兼容 vs 国产 vs 进口

易损件选型，不是越贵越好，也不是越便宜越划算。要看使用场景 + 精度要求 + 预算。

5.1 选型 4 个原则

  1. 同规格匹配：型号、尺寸、性能参数必须与原装一致
  2. 质量稳定优先：不追求最便宜，要追求故障率最低
  3. 品牌可兼容：不是必须原厂，但要选有质量保证的兼容厂
  4. 关键件用原厂：称重传感器、速度传感器、仪表建议原厂

5.2 各易损件选型建议

易损件推荐可接受不推荐
称重传感器原厂同等级国产（如 HBM / 柯力 / 中航）无证小厂 / 价格 <1000 的
速度传感器原厂国产同规格（光电式推荐欧姆龙 / 奥托尼克斯）二手 / 翻新
仪表原厂同系列升级不同厂家（调试工作量大）
托辊 / 托辊轴承同规格（不限定厂家）国产优质（SKF / FAG / NSK / 人本）杂牌（轴承 3 个月内可能坏）
皮带原规格（不限定厂家）国产优质（双箭 / 永固 / 宝通）小厂无标
信号电缆RVVP 4×0.75 屏蔽国标 RVVP非标 / 无屏蔽
限位橡胶 / 密封原规格耐油丁腈橡胶普通橡胶（不耐油）
清扫器刮板聚氨酯（PU）硬质合金（高磨琢性物料）普通橡胶（不耐磨）

5.3 国产 vs 进口的实际选择

很多用户觉得"进口 = 可靠"，其实不一定：

  • 进口优势：工艺成熟、品牌稳定、技术资料全
  • 进口劣势：价格高 2-5 倍、供货周期长（2-4 周）、售后慢、特殊规格难配
  • 国产优势：性价比高（1/3-1/2 价格）、供货快（1-2 周）、售后及时、可定制
  • 国产劣势：质量参差不齐、需选优质品牌、长期稳定性待验证

实用建议：

  • 关键件（传感器、仪表）→ 进口或国产高端（HBM、柯力、中航）
  • 通用件（托辊、皮带、电缆）→ 国产优质（SKF、人本、双箭）
  • 小件（密封、刮板、限位）→ 国产通用即可

6. 更换 SOP：4 个典型场景

4 个典型更换场景的完整 SOP，按步骤执行：

6.1 场景 1：单个托辊更换（最常见，30 分钟）

  1. 停机、断电、挂牌
  2. 用扳手拆卡簧 / 螺栓
  3. 取出旧托辊（注意轴向定位）
  4. 检查托辊座（磨损、变形）
  5. 装新托辊（轴承加润滑脂）
  6. 调整水平度 ≤0.5mm
  7. 装卡簧 / 紧固螺栓
  8. 手拨测试（转动灵活）
  9. 通电试运行 5 分钟

6.2 场景 2：皮带更换（最复杂，4-8 小时）

  1. 停机 4-8 小时（提前安排）
  2. 松张紧装置（释放张力）
  3. 分段切割旧皮带（注意安全）
  4. 拆下旧皮带（卷好）
  5. 穿新皮带（从头部到尾部）
  6. 做接头（硫化或机械）
  7. 调整张紧装置（皮带张力符合设计值）
  8. 调跑偏（防偏辊）
  9. 空载试运行 30 分钟
  10. 负载试运行 1 小时
  11. 做精度校准（皮重 + 动态精度）

6.3 场景 3：单个称重传感器更换（高风险，2-3 小时）

  1. 停机、断电
  2. 记录原传感器数据（容量、灵敏度、信号电压）
  3. 拆信号电缆（标记 + / -）
  4. 松开限位装置
  5. 卸旧传感器（注意预压缩量）
  6. 清洁传感器座
  7. 装新传感器（预压缩量 0.2-0.5mm）
  8. 调整限位间隙（左右 ≤2mm、上下 ≤3mm）
  9. 接电缆（+ / - 不能接反）
  10. 通电测试信号电压
  11. 调零点（空载）
  12. 调量程（实物砝码 / 链码）
  13. 做动态精度测试（≤±0.25%）

6.4 场景 4：全车大修（停产 1-2 天）

  1. 停产 1-2 天
  2. 全部托辊更换
  3. 皮带评估（必要时更换）
  4. 称重传感器 / 速度传感器评估（必要时更换）
  5. 限位装置全部更换
  6. 电缆 / 接线端子检查
  7. 秤架除锈刷漆
  8. 重新组装 + 精度调试
  9. 72h 跑合
  10. 申请 JJG 195 复检
  11. 出年度维护报告

7.2 采购策略

  1. 长周期件提前备：称重传感器、速度传感器、仪表供货周期 2-4 周，建议备用 1 套，避免突发停机
  2. 短周期件年度采购：刮板、限位、密封、轴承年初一次采购，分批使用，节约成本
  3. 皮带按需采购：皮带价值高、存放占地，按需采购，不囤货
  4. 批量采购打折：多家秤统一品牌 / 规格，集中采购，单价降 10-20%
  5. 国产替代：通用件（托辊、皮带、电缆）国产优质品牌，成本降 30-50%

8. 更换 5 大常见问题 FAQ

Q1：易损件是按时间换还是按状态换？

A：按状态换为主，按时间为辅。

  • 按状态换（推荐）：短寿命件（刮板、密封、限位）磨损到一定程度就换，不等到坏
  • 按时间换（兜底）：长寿命件（传感器、仪表）即使没坏，使用 5-8 年后建议评估更换，避免突发故障

判断逻辑：磨损量 / 剩余寿命 / 故障风险 哪个先到，就以哪个为更换依据。

Q2：能不能用兼容件代替原厂件？

A：分情况：

  • 通用件：可以（托辊、皮带、电缆、刮板、密封）
  • 关键件：不建议用杂牌（传感器、速度传感器、仪表）
  • 精度影响：称重托辊必须同厂家同型号，不同厂家的托辊皮重差异可达 5-10%

建议关键件用原厂 / 国产高端，通用件用国产优质，性价比最优。

Q3：皮带秤的皮带和普通输送带有什么区别？

A：皮带秤用的皮带要求更高：

  • 厚度均匀：覆盖胶厚度误差 ≤±0.5mm（影响称重精度）
  • 接头平整：硫化接头平整度 ≤1mm（影响称重段）
  • 无接头优先：称重段长度内无接头（无法做到时，机械接头误差大、不推荐）
  • 抗拉强度均匀：芯层（EP / NN）厚度、张力均匀

选型时不是越厚越好，是越均匀越好。建议选用皮带秤专用皮带（厂家定制）或国标一级品。

Q4：清扫器刮板多久换一次？

A：取决于物料磨琢性 + 刮板材质：

  • 普通物料（煤、粮食、化肥）：聚氨酯刮板 6-12 个月
  • 磨琢性物料（焦炭、矿石、水泥熟料）：硬质合金刮板 3-6 个月
  • 粘性物料（湿粘土、糖蜜）：聚氨酯 3-6 个月

判断标准：刮板磨损厚度 >50% 或边缘缺口 >5mm 时立即更换，不要等到刮不干净再换（物料进入秤架会导致精度劣化）。

Q5：易损件国产和进口的差距有多大？

A：看具体件：

  • 称重传感器：进口（如 HBM、梅特勒）vs 国产高端（如柯力、中航）差距 5-10%，价格差 2-3 倍。贸易结算秤建议进口或国产高端，一般秤国产足够
  • 托辊 / 轴承：进口（如 SKF、FAG）vs 国产（如人本、洛阳 LYC）寿命差 30-50%，价格差 1.5-2 倍。非关键位置国产足够，称重段建议进口
  • 皮带：进口 vs 国产优质，寿命差 20-30%，价格差 1.5-2 倍。国产双箭 / 宝通完全可替代
  • 信号电缆 / 密封 / 刮板：进口 vs 国产几乎无差距，国产即可

实用原则：关键件（传感器、速度传感器、仪表）选进口或国产高端，通用件（托辊、皮带、电缆、密封）选国产优质，综合性价比最高。

❓ 常见问题 FAQ

皮带秤易损件寿命多久？

8 大类：短寿命 0.5-2 年（清扫器刮板、限位橡胶、密封件）；中寿命 2-5 年（托辊轴承、皮带、信号电缆）；长寿命 5-8 年（称重传感器、速度传感器、仪表）。年度总成本约设备价值的 5-8%。

易损件是按时间换还是按状态换？

按状态换为主、按时间为辅。短寿命件磨损到一定程度就换（不等到坏）；长寿命件即使没坏，使用 5-8 年后建议评估更换，避免突发故障。判断逻辑：磨损量/剩余寿命/故障风险哪个先到，就以哪个为更换依据。

皮带秤易损件国产和进口怎么选？

关键件（传感器、速度传感器、仪表）选进口或国产高端（HBM/柯力/中航）；通用件（托辊、皮带、电缆、密封）选国产优质（SKF/人本/双箭）。综合性价比最优，比全进口可省 30-50% 成本。

皮带秤皮带和普通输送带有什么区别？

皮带秤皮带要求：①厚度均匀（误差 ≤±0.5mm）②接头平整（硫化接头平整度 ≤1mm）③称重段长度内无接头④抗拉强度均匀。建议选用皮带秤专用皮带（厂家定制）或国标一级品，不是越厚越好而是越均匀越好。

皮带秤易损件年度预算多少？

按设备价值 5-8% 计提：5-10 万元设备年度预算 3000-6000 元；10-20 万元设备 6000-12000 元；20-50 万元设备 12000-25000 元。建议关键件备用 1 套（供货周期 2-4 周），通用件年初集中采购。
